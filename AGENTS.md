# AGENTS.md

## Tests
Do not run tests or test suites. Instead, tell me the exact command to run and ask me to share the results. Only run tests if I explicitly authorize it for the current task.

## TypeScript
Write clean, readable TypeScript. Always prefer standard top-level static imports. Do not use dynamic inline async imports (await import()) unless explicitly requested for code-splitting or server/client boundary reasons.

## Code Readability

Prefer code that communicates its behavior directly
through its structure.

Do not rely on idiomatic familiarity as a substitute
for clarity.

Avoid compressing multiple conceptual operations into
expressions that require mental expansion to understand.

Optimize for the reader's ability to reason about the
code, not the writer's ability to express it concisely.
